## Запуск и проверка

```bash
cd ~/translator
.venv/bin/python app.py                        # → http://localhost:8899
.venv/bin/python app.py --demo test_lecture.aiff --speed 2   # тест без микрофона
```

- Демо-режим гонит аудиофайл через весь живой конвейер (ASR → перевод → UI).
  Тестовые файлы: `test_lecture.aiff` (испанская «лекция», 6 фраз),
  `test_es.aiff` (короткий).
- Виртуальное окружение — `.venv/` в корне; зависимости — `requirements.txt`.
- Локальная LLM: Ollama, `ollama serve` + модель `qwen3:4b` (фолбэк
  `llama3.2:3b`). Без Ollama приложение работает, но чат/конспекты локально
  недоступны.
- Первый запуск качает модели faster-whisper (~2 ГБ) в кэш HuggingFace.

## Архитектура (решено, не менять без запроса Михаила)

```
app.py     FastAPI + uvicorn (127.0.0.1:8899). WS /ws — события движка в UI
           (emit() потокобезопасен, level троттлится 0.15 c). REST — см. ниже.
           Фоновые задачи: _ticker (tick/сек), _catchup_loop (каждые 600 с
           карточка «о чём были последние 10 минут» от локальной LLM).
engine.py  Аудио-конвейер v2: sounddevice 16 кГц → нейронный VAD Silero
           (из faster-whisper; чувствительность low/normal/high =
           порог 0.5/0.35/0.22) → двухступенчатый ASR faster-whisper int8:
             черновик small (хвост речи, каждые 0.5 с, beam 1) → partial;
             финал large-v3-turbo (завершённый сегмент, beam 5) → phrase.
           Сегмент завершён после ≥0.6 c тишины; без пауз >14 c —
           принудительная нарезка; PAD 0.25 c по краям (иначе клиппинг
           портит слова). Запись flac инкрементально (flush ~2 c).
           Перевод: translate() — argos ЛОКАЛЬНО основной (es→en→ru пивот),
           Google (deep-translator) фолбэк + детектор «перевод==оригинал»
           (Google под рейт-лимитом молча возвращает исходник).
db.py      SQLite data/studio.db: courses, lectures, phrases(t0,t1,es,ru,mark),
           notes, words, settings(k,v), chats. mark: ''|star|q|catchup.
           Настройки и их дефолты — DEFAULT_SETTINGS (единственное место).
llm.py     Один OpenAI-совместимый клиент. local = Ollama, БЕЗ инструментов
           (чат/конспект/catch-up/словарь). cloud = base_url+key+model из
           настроек (Uno LLM Gateway, OpenRouter и т.п.). АГЕНТ — только
           облако: files (строго внутри data/workspace, _safe_path),
           web_search (DuckDuckGo html), fetch_url, terminal (КАЖДАЯ команда
           ждёт «Разрешить» в UI: ApprovalBroker + threading.Event + WS),
           share_file (POST api.getuno.xyz/api/v1/deploy → {slug}.uno4.dev).
static/    index.html + app.css + app.js — весь UI (vanilla JS, без сборки).
live_translate.py  Ранний CLI-прототип. Не развивать, не удалять.
```

События WS: `hello, tick, level, status, partial, final, catchup, paused,
approval, agent_step`.

REST кратко: `/api/state`, `/api/lecture/{start,pause,resume,stop}`,
`/api/lectures`, `/api/lecture/{id}`, `/api/search`, `/api/courses`,
`/api/phrase/{id}/{mark,explain}`, `/api/note`, `/api/notes/replace`,
`/api/translate`, `/api/word`, `/api/word/save`, `/api/vocab[.tsv]`,
`/api/chat`, `/api/agent/approve`, `/api/summary/{id}[/save]`,
`/api/export/{id}.md`, `/api/share/{id}`, `/api/mics`, `/api/miclevel`,
`/api/settings`, `/api/audio/{id}`.

## Дизайн UI — жёсткое правило

**Только светлая тема.** Тёмный пёстрый вариант Михаил забраковал
(«всё криповое, чёрное, цветастое»). Стиль: светлый фон `#f6f6f5`, белые
карточки, один синий акцент, серые тона; цвет — только как тонкая смысловая
метка (полоска слева у «важное»/«не поняла»). Никаких тёмных тем и ярких
бейджей. Внешний вид и поведение — 1:1 по `design/studio-flow.html`:
у фраз нет постоянных кнопок, только меню «⋯» по наведению;
хоткеи ⌘1 важное / ⌘2 не поняла / ⌘L в заметки.

## Выученные грабли (не наступать повторно)

- **Google Translate** в течение дня начинает под рейт-лимитом возвращать
  исходный текст как «перевод» — поэтому основной перевод argos-офлайн,
  Google лишь фолбэк, и есть детектор `_looks_untranslated`.
- **Клиппинг ASR**: сегменты без запаса по краям портили слова
  (precios → piedras) — отсюда PAD=0.25 c.
- **Индексы аудиоустройств плавают** между сессиями → `_valid_device`
  проверяет сохранённый индекс; PortAudio err -50 = устройство не открылось
  на 16 кГц → фолбэк на родную частоту + ресемплинг в `_to16k`.
- **Ошибка старта не должна оставлять «полузапущенную» лекцию** — откат
  в `Engine.start` (запись удаляется, UI получает тост).
- **Неверный язык лекции ломает перевод молча** — после 3 непереведённых фраз
  подряд эмитится статус «проверь язык лекции».
- **Поиск по кириллице** в SQLite LIKE не работает регистронезависимо —
  фильтрация через `casefold()` в Python (`/api/search`).
- **Демо-режим** пользователь однажды принял за «моковые данные» — поэтому
  жёлтый warnbox + бейдж «ДЕМО»; не убирать.
- Звук в наушниках микрофон не слышит — для онлайн-видео нужен BlackHole
  (в планах, не сделано).

## Правила работы в этом репозитории

1. **Обновляй `PLAN.md`** (раздел «Статус») после каждой значимой доработки —
   это страховка от потери контекста между чатами.
2. Не отходи от прототипа и утверждённого стека; смену архитектуры —
   только с явного согласия Михаила.
3. Тексты UI — по-русски, обращение к пользователю в женском роде там, где
   это про Катю («не поняла»). Просто и без техножаргона.
4. Проверяй изменения конвейера демо-прогоном
   (`--demo test_lecture.aiff --speed 2`), UI — в браузере на localhost:8899.
5. Секреты (ключи облачной LLM, ключ Uno) живут только в настройках
   (таблица `settings` в data/studio.db) — не хардкодить, не коммитить.
6. `data/` (БД, flac, workspace) — пользовательские данные; не удалять
   и не коммитить. Лекции 2–3 в текущей БД — демо-данные.
7. Python без type hints и тяжёлых абстракций — короткий прагматичный стиль,
   докстринги по-русски; соблюдай существующий стиль модулей.
8. Тяжёлые импорты (sounddevice, faster_whisper, argos…) — ленивые, внутри
   функций: приложение должно стартовать быстро и падать поздно.
