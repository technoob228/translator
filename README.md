# Студия — живой перевод лекций (испанский → русский)

Приложение для ноутбука: слушает лектора, показывает живые субтитры
(испанский по словам + русский черновой перевод), режет речь на фразы,
пишет аудио, помогает вести заметки и делает конспекты с помощью ИИ.
Распознавание и локальный ИИ работают **офлайн**; интернет нужен только
для перевода (без сети остаётся испанский текст) и облачного агента.

## Запуск

```bash
cd ~/translator
.venv/bin/python app.py          # → http://localhost:8899
```

Тест без микрофона (проигрывает записанную «лекцию» через весь конвейер):

```bash
.venv/bin/python app.py --demo test_lecture.aiff --speed 2
```

## Установка на новый компьютер (Mac с чипом M)

Одна команда в Терминале (Cmd+Пробел → набрать «Терминал»):

```bash
curl -fsSL https://gist.githubusercontent.com/technoob228/b174b72520c7facee879b53e19d8f3e8/raw/studio-bootstrap.sh | bash
```

Установщик сам поставит всё нужное и скачает модели (~5 ГБ — делать дома
по Wi-Fi, займёт минут 15–30). Может один раз спросить пароль от компьютера
(для Homebrew). В конце на рабочем столе появится значок **«Студия»** — дальше всегда
просто двойной клик по нему, приложение откроется в браузере.

После установки: в приложении открыть **Настройки** и вставить ключ Uno —
без него не работают облачный ИИ и публикация конспектов. macOS спросит
разрешение на микрофон — нажать «Разрешить».

Все лекции, заметки, словарь и настройки хранятся в папке `data/` —
обновления её не трогают, ничего не пропадает.

## Обновление

Само: значок «Студия» при каждом запуске тихо подтягивает свежую версию
с GitHub (Михаил делает `git push` — у Кати само обновится при следующем
запуске). Вручную или через Claude Code с любого компьютера:

```bash
cd ~/translator && ./update.sh   # скачать свежее + перезапустить
```

## Что внутри (см. design/DESIGN.md и PLAN.md)

- **Распознавание** — faster-whisper, двухступенчато: черновик `small`
  каждые 0.7 с (текст «по словам»), финал `large-v3-turbo` по паузе.
  Аргентинский акцент держит заметно лучше Google Переводчика.
  Язык лекции определяется сам (или строго задаётся в Настройках).
- **Перевод** — Google (онлайн) с офлайн-фолбэком argos (es→en→ru).
- **ИИ** — локально Ollama `qwen3:4b` (чат про лекцию, сводки каждые
  10 минут, конспекты, словарь) или любой OpenAI-совместимый облачный
  провайдер (Настройки). В облачном режиме доступен «агент»: файлы
  в рабочей папке, веб-поиск, curl/терминал (каждая команда требует
  «Разрешить»), публикация конспектов по ссылке (хостинг Uno).
- **Ресурсы** — ≈5–6 ГБ RAM из 16 на M1 Pro (~35 %), в лимите.

## Экраны

Лекция (live + заметки/перевод/словарь/чат) → Стоп → конспект ИИ →
Библиотека (поиск по всем лекциям) → Повторение (плеер с перемоткой
по фразам) → Словарь (карточки, экспорт Anki) → Настройки.

Хоткеи на лекции: ⌘1 важное · ⌘2 не поняла · ⌘L фразу в заметки.
Метки ставятся через меню «⋯» на любой фразе.

## Советы по звуку (важнее любого софта)

1. Сидеть в первом-втором ряду.
2. Лучше — петличка/BT-микрофон ближе к лектору (выбор в Настройках).
3. Онлайн-лекции: захват системного звука через BlackHole.
