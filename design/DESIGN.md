# Lecture Copilot — дизайн приложения для лекций

Пользователь: Катя, не технарь, русскоязычная, немного английского.
Ситуация: лекции на испанском (аргентинский акцент), ноутбук Mac 13–14".
Задача: понимать лекцию в реальном времени, вести заметки, повторять после.

---

## 1. Три фазы использования = три режима приложения

**До лекции** → выбрала предмет («Economía I»), нажала «Начать» — всё.

**Во время** (главный режим, 80% ценности):
- живое распознавание по словам: серый «черновой» текст появляется по мере речи;
- к черновику сразу приклеивается черновой перевод;
- когда фраза закончилась (пауза) — она «финализируется»: уходит карточкой
  в общий транскрипт (RU крупно, ES мелко, время);
- параллельно: быстрые заметки, быстрый переводчик (ru/en ⇄ es), словарь,
  чат с локальной LLM;
- всё пишется: аудио + транскрипт + заметки с таймкодами.

**После**:
- плеер с «караоке»-транскриптом (клик по фразе — перемотка аудио);
- авто-конспект от LLM: краткое содержание, термины, вопросы к экзамену;
- экспорт: Markdown / PDF / Obsidian / Notion;
- словарь → карточки для повторения (или экспорт в Anki).

## 2. Карта функций

**Must (MVP):**
- live-распознавание с промежуточным (partial) текстом + переводом
- финализация фраз по паузе → транскрипт с таймкодами
- запись аудио лекции
- быстрые заметки (привязываются к текущему таймкоду)
- быстрый переводчик ru/en ⇄ es
- библиотека лекций по предметам, просмотр транскрипта после

**Should:**
- «⭐ важное» и «❓ не поняла» — горячие клавиши, ставят метку на таймкод
- клик по испанскому слову → мини-словарь (перевод, форма глагола) → «сохранить»
- чат с локальной LLM (Ollama) с контекстом текущего транскрипта:
  «объясни, что он сейчас сказал про инфляцию»
- авто-конспект после лекции, экспорт в Markdown
- catch-up: каждые ~10 минут LLM вставляет в ленту карточку
  «коротко: о чём были последние 10 минут» (для отвлёкшихся)

**Nice:**
- караоке-плеер при повторении; редактирование транскрипта
- личный словарь с интервальным повторением / экспорт в Anki
- поиск по всем лекциям
- оверлей-режим: узкая полоска субтитров поверх всех окон
  (когда на экране открыты слайды лектора)
- захват системного звука (BlackHole) для онлайн-лекций
- LLM-глоссарий на лету: термины подсвечиваются, наведение — определение

## 3. Визуальный стиль

Светлый и спокойный, «как родное приложение macOS»: белые карточки на
светло-сером фоне, один синий акцент, серые вспомогательные тона.
Цвет — только как тонкая смысловая метка (полоска слева у «важного» /
«не поняла»). Тёмная тема — не делаем (забракована).

## 4. Варианты интерфейса

### Вариант A — «Лента» (минимализм)

Один столбец, как телесуфлёр. Инструменты спрятаны в выдвижной ящик.

```
┌──────────────────────────────────────────────┐
│ ● REC 47:12  Economía I     [Aa] [🌐] [🛠]  │  ← тонкий хедер
├──────────────────────────────────────────────┤
│                                              │
│   12:03  Инфляция — одна из главных…         │  финализированные
│          La inflación es uno de…             │  карточки, скролл
│   12:04 ⭐ Три причины инфляции: …           │
│                                              │
├──────────────────────────────────────────────┤
│ ▌СЕЙЧАС  el banco central emite… ▮           │  ← закреплённая
│  черновой перевод: центральный банк выпуска… │    live-зона снизу
│  [⭐ важное] [❓ не поняла] [✎ заметка]      │
└──────────────────────────────────────────────┘
        [🛠] → справа выезжает ящик: Заметки | Перевод | Словарь | Чат
```

Флоу: старт → весь экран это транскрипт → инструменты по требованию →
стоп → экран «после лекции». Плюс: максимум текста, ничего не отвлекает,
идеально для 13". Минус: заметки не перед глазами — конспектировать неудобно.
Кому: «мне бы просто понимать, что происходит».

### Вариант B — «Кокпит» (активное конспектирование)

Два стабильных столбца: слева лекция, справа рабочая зона. Заметки видны всегда.

```
┌───────────────────────────┬──────────────────┐
│ ● REC 47:12  Economía I   │  МОИ ЗАМЕТКИ     │
├───────────────────────────┤  - инфляция =    │
│ транскрипт (скролл)       │    рост цен      │
│  12:03 Инфляция — одна…   │  - 3 причины:…   │
│        La inflación…      │  [+ вставить     │
│  12:04 ⭐ Три причины…    │    фразу ⌘L]     │
├───────────────────────────┼──────────────────┤
│ ▌СЕЙЧАС el banco central… │ Перевод|Словарь| │
│  черновик: центральный…   │ Чат   (табы)     │
│ [⭐] [❓] [✎]             │ es⇄ru: [____]    │
└───────────────────────────┴──────────────────┘
```

Флоу: во время лекции пишет заметки не уходя с экрана; ⌘L кидает последнюю
фразу транскрипта в заметку цитатой; перевод/словарь/чат — табы под заметками.
Плюс: конспект рождается прямо на лекции. Минус: транскрипту тесновато.
Кому: «хочу выйти с лекции с готовым конспектом».

### Вариант C — «Студия» (полноценное приложение)

Слева узкий рейл навигации — те же экраны нужны и «после лекции», поэтому
оболочка масштабируется на всё приложение. Центр — сцена, справа — контекст.

```
┌──┬────────────────────────────┬───────────────┐
│🎙│ ● REC 47:12   Economía I   │ КОНТЕКСТ      │
│📚│────────────────────────────│ [Заметки]     │
│📖│ транскрипт                 │ [Перевод]     │
│💬│   12:03 Инфляция — одна…   │ [Словарь]     │
│⚙️│   ~ catch-up: последние    │ [Чат LLM]     │
│  │     10 мин — о причинах…   │  (переключае- │
│  │────────────────────────────│   мые панели) │
│  │ ▌СЕЙЧАС el banco central…  │               │
└──┴────────────────────────────┴───────────────┘
 🎙 Лекция  📚 Библиотека  📖 Словарь  💬 Конспекты
```

Флоу: единая оболочка для live / библиотеки / повторения / словаря;
после «стоп» центр превращается в караоке-плеер, справа — авто-конспект
и кнопки экспорта. Плюс: одна модель интерфейса на всё, есть куда расти.
Минус: самый дорогой в разработке.
Кому: если приложение — «вторая память» на весь семестр, а не только субтитры.

### Дополнение к любому варианту — оверлей-режим

Кнопка «свернуть в полоску»: окно превращается в узкую always-on-top полоску
субтитров (2 строки: RU + черновик), остальной экран свободен под слайды/PDF.
Клик — развернуть обратно. Это отдельный маленький режим, не четвёртый вариант.

## 5. Ключевые флоу (общие)

**Старт лекции:** открыть → карточка предмета (или «+ новый») → «Начать» →
проверка уровня микрофона (полоска громкости, «вас слышно») → live.

**Пометка на лету:** у фраз ничего не висит постоянно. По наведению на
финализированную фразу появляется «⋯», клик — меню действий: важное,
не поняла, в заметки цитатой, объяснить в чате, копировать.
Для последней прозвучавшей фразы то же доступно хоткеями (⌘1/⌘2/⌘L)
без открытия меню. Полный кликабельный флоу — `design/studio-flow.html`
(кнопка «Экскурсия по сценариям» — 25 шагов по всем кнопкам).

**Слово непонятно:** клик по слову в испанской строке → поповер: перевод,
базовая форма, пример из этой же лекции → [Сохранить в словарь].

**Конец лекции:** «Стоп» → экран итога: длительность, N фраз, M заметок,
K слов → [Сделать конспект] (LLM) → редактируемый Markdown → [Экспорт].

**Повторение:** Библиотека → лекция → плеер: клик по фразе = перемотка,
подсветка текущей фразы; заметки и ⭐/❓ на таймлайне плеера.

## 6. Технический стек (утверждено)

Железо: MacBook Pro M1 Pro, 16 ГБ. Бюджет ресурсов: ≤ 50–60 % RAM/CPU.

**Распознавание (двухступенчатое, faster-whisper / CTranslate2, int8):**
- черновик: `small` (~0.5 ГБ RAM) — скользящее окно 4–5 с,
  перетранскрипция каждые ~0.7 с → живой текст «по словам»;
- финализация: `large-v3-turbo` (~1.5 ГБ) — когда VAD поймал паузу,
  фраза перегоняется начисто и попадает в транскрипт;
- всё офлайн, язык фиксирован `es`, beam_size=1 для черновика,
  beam_size=5 для финала.

**Перевод:** deep-translator (Google) онлайн; офлайн-фолбэк argos-translate
es→ru; при отсутствии сети показываем испанский оригинал.

**Локальная LLM (по умолчанию):** Ollama + `qwen3:4b` (q4, ~2.6 ГБ, Metal —
не грузит CPU). Русский и испанский у Qwen заметно лучше, чем у Llama 3.2 3B
(её оставить фолбэком). Роли: чат «что он сказал», catch-up-сводки,
черновик конспекта, определения терминов. Подключение — OpenAI-совместимый
эндпоинт Ollama `http://localhost:11434/v1`, ключ не нужен.

**Облачная LLM (опция в настройках):** любой OpenAI-совместимый провайдер —
поля base_url + api_key + model. Работает и Uno LLM Gateway
(https://api.getuno.xyz, 300+ моделей), и OpenRouter/OpenAI/DeepSeek.
Клиент один и тот же, что для Ollama.

**Режим «агент» (только с облачной моделью):** инструменты чата —
- файлы: читать/создавать/править ТОЛЬКО внутри папки данных приложения
  (конспекты .md, презентации .html/reveal.js);
- web_search + fetch_url (curl GET с лимитом размера);
- терминал: каждая команда показывается пользователю с кнопкой
  «Разрешить» до запуска, деструктивные — с красным предупреждением;
- «Поделиться»: multipart POST /api/v1/deploy на хостинг Uno →
  публичная ссылка https://{slug}.uno4.dev (для конспектов и презентаций).
Локальной 4B-модели терминал и интернет не даём — только перевод,
объяснения, конспекты и файлы в рабочей папке.

**Бюджет памяти:** small 0.5 + turbo 1.5 + qwen3:4b 2.6 + приложение ~0.7
≈ 5.3 ГБ (~33 % от 16 ГБ) — с запасом внутри лимита 50–60 %.
CPU: черновой ASR — постоянные ~1.5–2 ядра, финализация — короткие
всплески; LLM живёт на GPU (Metal) и выгружается после простоя
(keep_alive 10 мин).

**Хранение:** SQLite (лекции, фразы, заметки, словарь, метки) +
аудио flac в папке предмета. Экспорт: Markdown (+ Obsidian), PDF печатью.

**Оболочка:** локальный Python-сервер + браузер (MVP), дальше Tauri
для «настоящего приложения» и оверлея-полоски.

## 7. Рекомендация

Собираем **Студию**: оболочка с левым рейлом, экран «Лекция» —
по прототипу `studio-flow.html` (меню «⋯» на фразах вместо постоянных
кнопок). Библиотека, словарь и конспекты живут в той же оболочке.
